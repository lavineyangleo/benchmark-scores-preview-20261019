## 分类与证据口径

- 一条成绩允许多个一级／二级指标，原始记录仅保存一次；分类统计可重复计入，不可相加当总数。
- 示例：GPQA归入自然科学及推理；MathVista归入视觉推理及推理；MMAU归入听觉理解与听觉推理。多标签代表相关能力，不能将总分解释成每个子能力的独立得分。
- MMLU-Pro overall等综合分保留待细分，不复制为医学、法律、工程等分科得分；AIR-Bench同名任务不自动分类。
- A为本次读取或从历史原表抽取；B为上游文献数值，未逐项核验；C为聚合快照，不作为同协议排名。
- 快照日期表示当时公开内容存在，不一定是首次公开日期。2026快照中的旧模型成绩不倒填到2023—2025。
- 不同提交可能重复刊载同一数值；这是证据出现记录，不是独立测量次数。原始v3成绩与历史新提取记录也保留独立来源，不做统计显著性推断。
